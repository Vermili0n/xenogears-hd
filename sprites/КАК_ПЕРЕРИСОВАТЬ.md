# Как перерисовать кадры спрайтов самому

Цепочка из четырёх шагов: **выбрать кадры → отрисовать на поде → посмотреть → установить**.
Все команды запускаются в PowerShell из папки `<XENO_SPRITES>`.

```
cd <XENO_SPRITES>
```

Что нужно:
- под на RunPod с GPU не слабее L40S (подойдут A40, A6000, RTX 4090; нужно от 24 ГБ видеопамяти) и диском от 60 ГБ;
- диск с местом под бэкапы (в скриптах — `<DATA_DRIVE>`);
- закрытый RetroArch на шаге установки.

---

## 1. Найти имя кадра

У каждого кадра есть имя вида `<группа>__<кадр>`. Проще всего найти его по картинкам:

| Что | Где лежат превью кадров |
|---|---|
| Готовые кадры (то, что в игре) | `ai\prod_work\<группа>\frames\*.png` |
| Исходные рендеры | `pod\report\prod\res_prod\v4\<имя>.png` |

Группы:
- герои: `h_fei`, `h_elly`, `h_citan`, `h_bart`, `h_billy`, `h_rico`, `h_emeralda_emeralda`, `h_emeralda_emeralda_adult`, `h_chuchu`, `h_maria`;
- сюжетные персонажи: `c_…`;
- массовка: `m_…`;
- бой: `b_…`;
- гиры: `g_…` (этим способом не перерисовываются, см. раздел 8).

Имя кадра — это имя группы, два подчёркивания и имя файла превью без `.png`:

- `ai\prod_work\h_elly\frames\428_0_045.png` → **`h_elly__428_0_045`**
- `ai\prod_work\m_7d47706ecb\frames\npc_003.png` → **`m_7d47706ecb__npc_003`**

Если не получается понять, какая группа на экране, включи дамп текстур и найди имя по нему.

## 2. Собрать задания: `tools\redraw_pick.py`

```
python tools\redraw_pick.py <кадры> [--hint "подсказка"] [--seed 7] [--out ai\redraw\<имя>]
```

- **`<кадры>`** — имена через запятую. Можно маской (`?` — один символ, `*` — сколько угодно) или просто именем группы, тогда берутся все её кадры. Крупный план головы (`…__head`) добавляется сам.
- **`--hint`** — уточнение к запросу, на английском. Дописывается и к кадру, и к голове.
- **`--seed`** — номер варианта, по умолчанию 7. Основная отрисовка шла с seed 42: с ним и без подсказки получится ровно та же картинка, поэтому скрипт такое не пропустит.
- **`--out`** — папка для заданий. По умолчанию `ai\redraw\<дата_время>`.

Двойники, то есть одинаковые кадры в разных группах (например, Мария-героиня и сюжетная Мария), рисуются один раз, и результат получают все.

В папке появятся:
- `jobs.json` — задания;
- `control\` и `boards\` — картинки для пода;
- `map.json` — куда разложить результат;
- `before\` — текущие рендеры для сравнения и отката;
- **`README.txt` — готовые команды для этой папки**.

### Примеры

**а) Один кадр Элли со спины, где ей нарисовали лицо:**
```
python tools\redraw_pick.py h_elly__428_0_045 --hint "back view seen from behind, the face is not visible" --out ai\redraw\elly_back
```

**б) Десять кадров подряд (040…049) по маске:**
```
python tools\redraw_pick.py "h_elly__428_0_04?" --hint "back view seen from behind, the face is not visible" --out ai\redraw\elly_back2
```

**в) Несколько разных кадров без подсказки, просто другой вариант:**
```
python tools\redraw_pick.py h_fei__2336_0_000,h_fei__2336_0_001 --seed 11 --out ai\redraw\fei_try
```

**г) Персонаж массовки, которому дорисовали хвост:**
```
python tools\redraw_pick.py m_7d47706ecb --hint "he has short cropped hair, no ponytail and no hair tie" --out ai\redraw\bearded
```

**д) Вся группа целиком (Мария: 354 кадра, 708 заданий, около 3 часов на одном L40S):**
```
python tools\redraw_pick.py h_maria --seed 11 --out ai\redraw\maria_all
```

Скрипт сразу пишет, сколько выйдет заданий и сколько это минут. Одно задание на L40S занимает около 15 секунд, на кадр приходится два задания: сам кадр и голова.

### Подсказки, которые уже проверялись (`tools\fix_jobs.py`, HINTS)

| Проблема | Подсказка |
|---|---|
| Нарисован спереди, а надо со спины | `back view seen from behind, the face is not visible` |
| Пропала повязка на глазу | `he wears a black eyepatch over one eye exactly where the sprite shows the dark patch` |
| Пропали очки (Ситан) | `he wears small round wire-rimmed glasses over his eyes` |
| Лишний хвост | `he has short cropped hair, no ponytail and no hair tie, the back of his head and neck show short hair` |
| Не та одежда | `he wears a long white doctor's coat exactly as the sprite shows it, not a dark jacket` (подставь своё) |
| Лицо вместо маски | `the face is covered by a white mask with dark slanted eye holes and red marks exactly as the sprite shows it, no human eyes are visible` (опиши свою маску) |
| Человек вместо зверя | `this is a dog with a dog muzzle, black nose and floppy ears, not a human face` |

Общее правило: описывай то, что **видно на пиксельном спрайте**. Спрайт — эталон.

## 3. Отрисовать на поде

1. В RunPod создай под: GPU L40S, шаблон PyTorch, диск от 60 ГБ.
2. В **Connect → SSH over exposed TCP** возьми адрес и порт, например `root@<POD_HOST> -p <POD_PORT>`.
3. Открой `ai\redraw\<имя>\README.txt` и замени в нём `HOST` и `PORT` на свои. Дальше команды по порядку:

**3.1. Настройка, только для нового пода** (около 10 минут: ставятся библиотеки и качается модель):
```
scp -P PORT pod\setup_infer.sh pod\infer_pod.py root@HOST:/workspace/
ssh -p PORT root@HOST "mkdir -p /workspace/lora /workspace/redraw"
scp -P PORT lora\klein_v4\xeno_klein_v4.safetensors root@HOST:/workspace/lora/
ssh -p PORT root@HOST "cd /workspace && (setsid nohup bash setup_infer.sh > setup_infer.log 2>&1 &)"
ssh -p PORT root@HOST "tail -2 /workspace/setup_infer.log"
```
Последнюю команду повторяй, пока в выводе не появится `SETUP_OK`.

**3.2. Залить задания и запустить отрисовку.** Команда запуска есть в README уже с именем папки и seed. Для примера «а»:
```
scp -P PORT -r ai\redraw\elly_back root@HOST:/workspace/redraw/
ssh -p PORT root@HOST "cd /workspace && (setsid nohup sh -c 'HF_HOME=/workspace/hf python infer_pod.py --jobs redraw/elly_back/jobs.json --out redraw/elly_back/res --crop --cfg 4 --seed 7 --lora lora/xeno_klein_v4.safetensors; echo RENDER_DONE' > redraw/elly_back/infer.log 2>&1 &)"
```
Отрисовка идёт на поде сама. Окно можно закрыть, и даже выключить ПК.

**3.3. Проверить ход работы:**
```
ssh -p PORT root@HOST "tail -2 /workspace/redraw/elly_back/infer.log; ls /workspace/redraw/elly_back/res/v4 | wc -l"
```
Готово, когда в логе есть `RENDER_DONE`, а число файлов равно числу заданий.

**3.4. Скачать результат:**
```
scp -P PORT -r root@HOST:/workspace/redraw/elly_back/res ai\redraw\elly_back\
```

**3.5. Остановить под в RunPod.** Он тарифицируется почасово. Если будешь пробовать другие варианты, остановить можно и позже: настройку (3.1) на том же поде повторять не нужно.

Если ключ не стандартный (`<SSH_KEY>`), добавь в каждую команду `ssh` и `scp` параметр `-i $HOME\.ssh\<SSH_KEY>`.

---

## 4. Посмотреть глазами

Сравни `ai\redraw\<имя>\res\v4\*.png` с `ai\redraw\<имя>\before\*.png`.

Если не понравилось, собери новую папку с другим `--seed` или другой подсказкой (шаг 2) и повтори шаги 3.2–3.4 на том же поде. Старую папку на поде переиспользовать нельзя: отрисовщик пропускает уже готовые файлы.

---

## 5. Установить (RetroArch закрыт)

```
python tools\fix_apply.py ai\redraw\elly_back\res\v4 --map ai\redraw\elly_back\map.json --no-record
python tools\redraw_finish.py
```

- **`fix_apply.py`** раскладывает новые рендеры вместо старых и пересобирает затронутые группы целиком: нарезка на части, цвета, двойники. Потом кладёт их в пак. Старые рендеры один раз сохраняются в `pod\report\prod\res_prod_prefix\v4`. Обычно это занимает несколько минут.
- **`redraw_finish.py`** переводит появившиеся в паке PNG обратно в BC7 и заново заделывает швы между частями. Занимает 3–8 минут. Бэкап PNG и прежних BC7 лежит в `<DATA_DRIVE>\xeno_redraw_backup\<время>`, лог — в `pod\report\redraw_finish.log`.

Если `redraw_finish` по какой-то причине не прошёл, новые кадры в игре всё равно видны: ядро берёт PNG раньше BC7. Его просто нужно запустить ещё раз.

После установки запусти игру (`<RETROARCH_DRIVE>\RetroArch\Xenogears HD.cmd`) и найди это место. Готовые кадры после нарезки можно посмотреть и без игры: `ai\prod_work\<группа>\frames\`.

---

## 6. Откат

Вернуть то, что было до перерисовки (RetroArch закрыт):
```
python tools\fix_apply.py ai\redraw\elly_back\before --map ai\redraw\elly_back\undo_map.json --no-record
python tools\redraw_finish.py
```

---

## 7. Переносной архив

После любых изменений пака переносной архив устаревает. Удали старые части в `<DATA_DRIVE>\XenogearsHD_portable\parts\` и собери заново (RetroArch закрыт, около 15 минут):
```
python tools\make_portable.py --out <DATA_DRIVE>\XenogearsHD_portable\parts\Xenogears_HD_RUS.zip --split-gb 2
```

---

## 8. Если что-то пошло не так

| Сообщение или ситуация | Что делать |
|---|---|
| `RetroArch is running - close it first` | Закрыть RetroArch и повторить. |
| `fix_apply`: `NOT installed (RetroArch running…)` | То же: закрыть RetroArch и запустить `fix_apply` ещё раз. |
| `fix_apply`: `N not rendered: [...]` | Часть рендеров не скачалась. Проверь `res\v4` (3.3) и скачай снова. |
| На поде нет `SETUP_OK` | Посмотри `tail -30 /workspace/setup_infer.log`. Обычно это сбой скачивания модели: запусти настройку ещё раз. |
| `gear (LoRA v2) frames are not handled` | Гиры рисуются другой моделью (LoRA v2), этим скриптом их не перерисовать (см. `tools\gear_redraw.py`). |
| `no such frame` | Опечатка в имени. Сверь его с превью (раздел 1). |
| Перерисовал ходьбу Элли (набор `428_0`) | На картах леса 934/936 игра берёт **копию** этого набора, и она не обновится: её нужно перенести отдельно. |
| После установки что-то хуже, чем было | Откат (раздел 6). |

Если что-то непонятно, сохрани вывод команды: по нему проще разобраться.
